How search is configured

The ranking, synonyms, filters and promoted results behind every search box, declared as data. This view reads the prototype’s live configuration.

Why it is hereWhen practice areas, offices or content types change, search changes by editing configuration, not by redevelopment (R42). In a first build this lives in configuration files; an editing screen for the synonyms is a later-phase option.
