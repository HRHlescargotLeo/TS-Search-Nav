Module library

Every navigation and search component in the prototype, shown once. Nothing here is a page component: page templates are not changed by this work.

1. Mega-menu panel

Used by every primary item: an overview link that matches the destination’s H1, the section’s children, and one featured item. Open any item in the header above to see it live.

BehaviourOpens on hover, keyboard focus or click; never hover-only. Escape closes it and returns focus to the item. At mobile width the same panels open in place under a Menu button, with the same content (R11).

2. Filterable service tree

BehaviourThe number beside a practice opens its sub-services. Typing filters practices and sub-services together, opens the branches that matched, and uses the same synonym map as search. The same module sits in the Services menu and on the A–Z page.

3. Search box with typeahead

BehaviourServices, sectors and topics first, then people, then pages. A suggestion found through a synonym says so (‘matches gdpr’). With a scope set, the same box behaves for its section: in People, choosing a service shows the people in it. Up and Down move, Enter chooses, Escape closes.

4. Filter chips

BehaviourA dashed chip is a section scope; removing it widens the search to the whole site. A solid chip is a filter. Each is one click to remove.
