Travers Smith: search and navigation prototype

A lo-fi, clickable model of the navigation and search we propose for traverssmith.com, built to be reacted to in the workshop and changed afterwards. It shows structure and behaviour only. Visual design is a later phase and is not represented here.

Version 1 7 October 2026 Status: for Workshop 1

About the contentService and sub-service names are Travers Smith’s own, from the live A–Z. Every person, article, deal, event and document is fictional, shaped like the real site so the search can be judged against realistic content. Links that go nowhere go nowhere on purpose.

How to use it in the roomThis is one worked answer to the navigation decisions, not the decision itself. It is here so the room can react to something concrete; the options it does not take are still open.

How to review this

  • Yellow notes explain behaviour a screenshot cannot show. Red notes are questions we need answered. The button at the bottom right hides them for a clean view.

  • Menus open on hover, focus or click, and close with Escape. Everything works from the keyboard.

  • Narrow the browser, or open it on a phone, to see the same navigation at mobile width.
