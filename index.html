Travers Smith: search and navigation prototype

A lo-fi, clickable model of the navigation and search we propose for traverssmith.com, built to be reacted to in the workshop and changed afterwards. It shows structure and behaviour only. Visual design is a later phase and is not represented here.

Version 1.1 7 October 2026 Status: for Workshop 1

About the contentService and sub-service names are Travers Smith’s own, from the live A–Z. Every person, article, deal, event and document is fictional, shaped like the real site so the search can be judged against realistic content. Links that go nowhere go nowhere on purpose.

How to use it in the roomThis is ClerksWell’s proposal, built from the review’s findings, and it is here to be changed. The options it does not take are still recorded in the observations report, and the room can ask for any of them.

ScopeEverything in this prototype is navigation or search: the header and its menus, the footer, the search box, the results page and the two section searches that exist today (People and Knowledge). Page templates and the components on them are not changed. Service, profile and other pages appear only as placeholders for the menus and search to land on.

Beyond a first phase: listed, not built

Proven on the same engine elsewhere: location-aware search, reference-format matching, sources outside the CMS. To be scoped: search analytics, saved searches and alerts, Word and PowerPoint text, editor-maintained synonyms, a semantic layer. The default answer for each is no; The workshop and the written feedback afterwards record the answer rather than assuming it.
